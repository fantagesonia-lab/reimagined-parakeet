# Pixie Closet

A browser dress-up character creator in the style of an MMORPG character screen. Open `index.html` in any browser, no install needed.

- The base body is traced 1:1 from `tools/reference.jpg` (front, side and back views), so the character matches the reference exactly.
- 98 items across 9 slots: hair, tops, bottoms, full outfits, shoes, hats, face accessories, back items and weapons. Every item draws for front, side and back.
- 8 skin tones, 8 eye colors, 14 hair colors, a 16-color dye palette plus a custom color picker for every item.
- Job outfit presets (Warrior, Magician, Bowman, Thief, Pirate and more), randomize, 3 closet save slots, shareable outfit codes, snapshots and chat bubbles.
- 7 animated maps. Turn the character with the arrows, by dragging, or with the arrow keys.

## How it works

Clothes are drawn as masks on the reference body's own pixel grid and shaded from the body's own shading, so every garment hugs the original contours.

| File | Role |
| --- | --- |
| `src/sprites.js` | Body sprites (generated by `tools/gen_sprites.py`) |
| `src/engine.js` | Pixel compositing, skin/eye recolor, blinking |
| `src/items.js` | The wardrobe |
| `src/scenes.js` | Map backgrounds |
| `src/ui.js`, `src/app.html` | Interface |

Run `python3 build.py` after editing `src/` to rebuild `index.html`. `node tools/sheet.js out.png hair` renders a contact sheet of any category for checking art.
